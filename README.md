# KOPPKAS

Sistem operasional organisasi Pemuda Kampung Sawah Kaum.

## Stack awal

- Next.js App Router
- React
- TypeScript (strict)
- CSS design tokens dan responsive styles
- Lucide icons

## Menjalankan secara lokal

Persyaratan: Node.js 20.9+.

```bash
npm install
npm run dev
```

Buka http://localhost:3000.

## Pemeriksaan

```bash
npm run typecheck
npm run lint
npm run build
```

## Status implementasi

Tahap 01 membangun fondasi antarmuka aplikasi: navigasi modul, dashboard shell, responsive sidebar, pencarian modul, dan metadata PWA.

Data dashboard saat ini sengaja tidak diisi angka contoh. Autentikasi, database, izin akses, dan integrasi realtime belum dihubungkan; jangan gunakan tampilan ini untuk operasional atau pencatatan keuangan sebelum backend dan kontrol akses selesai.
